# MBox — собственный VPN для Android через QUIC и HTTPS

[English](README.md) · [Android](docs/ru/GETTING_STARTED.md) · [Поднять сервер](docs/ru/SERVER_QUICKSTART.md) · [Документация](docs/ru/README.md) · [Изменения](CHANGELOG.ru.md)

**Кандидат `1.0.0-beta.4.4`, Android `versionCode=11`.** Экспериментальный **prerelease**, не RC1 и не сертификат независимого аудита. Публикация GitHub Release и подписанного APK считается завершённой лишь после проверки последнего SHA, CI и файла релиза.

MBox создаёт Android VpnService/TUN и шифрует трафик с помощью Noise (`Noise_NKpsk0_25519_AESGCM_SHA256`). Два внешних **входа**: прямой QUIC/HTTP3 через VPS gateway или Chromium Cronet HTTPS/HTTP2 через необязательный FastCGI-фронтенд. **AUTO транспорта** предпочитает QUIC и использует HTTPS при отказе. REG.RU — один из вариантов входа, а не страна выхода.

```text
                     +-- QUIC/HTTP3 --> шлюз VPS ------+
Android VPN + Noise -|                                 +--> MBox origin --> sing-box SOCKS5 --> DK / KZ / другой выход
                     +-- HTTPS/Cronet --> FastCGI ------+
```

**UDP в beta.4.4:** при QUIC UDP приложений предпочитает отдельный аутентифицированный QUIC DATAGRAM. Канал открывается только при реальном UDP-трафике, засыпает при простое и безопасно присоединяется повторно к той же Noise-сессии с новыми AEAD-ключами/эпохой. **Постоянных DATAGRAM PING нет.** Пока канал не готов, **AUTO UDP** использует надёжные MBox streams. TCP и управление всегда идут через streams. Скрытая диагностика (семь нажатий на MBox) содержит выбор `AUTO` (по умолчанию), `STREAMS only`, `DATAGRAM only` (без UDP fallback; пакеты могут теряться). Обычным пользователям переключатель не показываем.

**Подписки и выходы:** одна постоянная секретная HTTPS-ссылка может выдавать несколько профилей beta.4.4. **v1 подписок** остаётся для beta.4.3 (выход по умолчанию); **v2** передаёт дополнительный `egress_id` для выбора разрешённого origin выхода. `MBD1`/`MBD2` — форматы payload Noise OPEN, **не версии HTTP API**. Старые клиенты получают выход по умолчанию. Дания и Казахстан равноправны для нового клиента, но default нужен для совместимости. Разные страны не означают независимые origin.

**Проверенная совместимость:** разработчик протестировал обновление подписки и подключение beta.4.3, а также датский и казахстанский SOCKS5-выходы в beta.4.4. Это не гарантия для всех предыдущих версий и сетей. Без QUIC продолжает работать HTTPS, DATAGRAM не нужен для аутентификации соединения.

## Как начать

1. **После публикации** скачайте **production-signed** `MBox-1.0.0-beta.4.4-android-arm64.apk` в [GitHub Releases](https://github.com/RegSirius06/mbox/releases). Требуются Android 10+, ARM64.
2. Импортируйте `mbox://` или секретную HTTPS-ссылку подписки от администратора. APK не содержит готовых пользовательских ключей.
3. Выберите профиль и подключитесь. Обновляйте APK **поверх** старого с тем же сертификатом; удаление приложения может уничтожить профили.
4. Для собственного сервера: [первичная установка](docs/ru/SERVER_QUICKSTART.md), [эксплуатация](docs/ru/BETA44_OPERATIONS.md), [подписки и выходы](docs/ru/MBOX_SUBSCRIPTIONS.md), [безопасность](docs/ru/SECURITY.md).

**Ограничения:** остаются испытания физической утечки IPv4/IPv6/DNS/UDP, Android Lockdown, энергопотребления, длительной стабильности и лимитов CPU FastCGI на REG.RU. Хостинг может ограничивать/завершать процессы. **QUIC DATAGRAM не исправляет проблему CPU REG.RU**, так как обходит этот фронтенд. Нет гарантии анонимности и работы при любом DPI. Не публикуйте PSK, `mbox://`, токены подписок, пароли, конфигурации и ключи подписи.
