## 1.0.0-beta.4.4 — UDP DATAGRAM по требованию, страны выхода и эксплуатация / 2026-11-21

- Отдельный аутентифицированный QUIC DATAGRAM для UDP: запуск по пакету, сон при простое, новые AEAD-ключи/эпохи при повторном присоединении, replay-защита и fallback на streams. Периодических PING нет.

- Подписка v2 с аутентифицированным `egress_id` и локальными разрешёнными SOCKS5, v1 остаётся для beta.4.3 и выхода по умолчанию. Реально проверены DK/KZ.
- SSH-панель, имена выходов, исправленные права `root:mbox 0640` для `egress.json`, безопасный read-only `install.sh --check`, раздельный деплой компонентов.
- Известные проблемы: не устранены ограничения CPU/воркеров FastCGI REG.RU; нужны измерения батареи и физические тесты утечек. См. [примечания](RELEASE_NOTES.ru.md).

## 1.0.0-beta.4.2 — веб-панель и подписки / 2026-11-15

- **Новая веб-панель:** повседневное управление пользователями, сроками, лимитами сессий, PSK, выдачей/отзывом подписок и HTTPS-точками входа без необходимости запускать `mboxctl` по SSH. Добавлены массовые операции, диагностика и редактирование `mbox.conf` с проверкой, бэкапом и применением. CLI сохраняется для восстановления и расширенных команд; полное покрытие всех `mboxctl` команд через UI **не заявляется**.
- **Постоянные HTTPS-подписки:** динамическая выдача конфигурации, одна основная ссылка на пользователя при повторном просмотре, учёт выданных токенов, отзыв, настраиваемый публичный URL (`/api/v2` поддерживается). Изменение пути требует обновить ранее разосланные ссылки.
- **Android:** до 12 HTTPS-подписок, до 12 профилей в каждой, выбор входа, независимое обновление/кэш и сохранение прямых `mbox://`. Android 10+, ARM64, `versionCode=9`.
- **Совместимость:** старые прямые профили подключаются через HTTPS/FastCGI. Старый QUIC в текущем развёртывании не работает с прежними TLS-параметрами/сертификатом; актуальный QUIC требует обновлённого профиля. Несовместимость wire-протокола не подтверждена.
- **Проверено оператором:** работа панели и публичного endpoint подписок, сохранение конфигурации и обновлённого Caddy-маршрута, импорт и подключение HTTPS-подписки, обновление установленной APK без удаления данных.
- **Ограничения:** QR-превью и UX панели/Android требуют доработки; нет квот трафика и строгих лимитов зарегистрированных устройств; многохостовый HTTPS failover и длинные soak/leak/Lockdown тесты не завершены. Это prerelease beta, не RC1.

См. [полные примечания к beta.4.2](RELEASE_NOTES.ru.md).
