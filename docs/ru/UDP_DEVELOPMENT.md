# Разработка UDP (после beta.3)

**Состояние: кодек + лабораторный UDP-тракт, по умолчанию UDP выключен на Android и сервере.**
Рабочий TCP/Noise-тракт и политика fail-closed остаются прежними.

Создан `common/udpwire`: версионированные UDP-датаграммы MBox с `flow_id`,
кодирование/декодирование HEV FWD UDP (`SOCKS CMD=0x05`, UDP-in-TCP), IPv4/IPv6,
предельный размер 1232 байта, отсутствие фрагментации, неявного DNS и физического
UDP fallback. Парсеры ограничивают размеры до аллокации и отклоняют повреждённые
пакеты. Покрыты unit/property/fuzz тестами.

План передачи:

```
HEV UDP-in-TCP -> локальный MBox SOCKS -> Noise/HTTPS -> REG.RU -> RU origin
 -> SOCKS5 UDP ASSOCIATE на sing-box 127.0.0.1:2080
 -> заданный outbound (включая зарубежный каскад)
```

**Нельзя** заменять sing-box произвольным `net.DialUDP` с RU VPS: иначе
пользовательский DNS/UDP может выйти напрямую из РФ, минуя выбранный каскад.

Первый этап — кодек; второй — лабораторный тракт с ограниченными session/flow
очередями, SOCKS UDP ASSOCIATE, проверкой обратного адреса и unit-тестами.
Дальше обязательны интеграционные тесты с реальным sing-box/REG.RU, Wi-Fi/LTE
packet capture, Always-on Lockdown, тесты падения процесса, DNS, QUIC, STUN,
IPv6 и длительная нагрузка.

**QUIC** — протокол, использующий UDP. Нативный UDP даст возможность
транслировать QUIC клиентских приложений, но сам по себе не означает,
что внешний HTTPS-транспорт MBox должен перейти на QUIC.

Полная спецификация и ограничения: `docs/UDP.md`.

## Этап 2 — UDP-ассоциация сессионного уровня (только лаборатория)

Код Go-клиента и origin теперь содержит путь `HEV CMD=0x05 → MBox UDP frames
через Noise/HTTPS → SOCKS5 UDP ASSOCIATE локального sing-box → ответ через
зашифрованный DOWN`. С обычного Android этот режим пока **не активирован**.

Ключи `transport.enable_udp_lab=true` должны быть явно заданы с обеих сторон;
Go-клиент дополнительно требует `--developer-mode`. По умолчанию оба значения
`false`. Android не получает опцию включения через пользовательскую ссылку.
Стандартный SOCKS `UDP ASSOCIATE (0x03)` остаётся запрещённым локально.

Лимиты: до 16 UDP-flow на MBox-сессию, 32 ожидающих датаграммы на поток,
128 датаграмм/с, 64 назначения на поток, полезная нагрузка максимум 1232 байта,
таймаут простоя 2 минуты. Очереди учитываются в глобальном бюджете памяти,
ресурсы освобождаются при закрытии сессии. Прямые UDP-сокеты к сайтам на
RU VPS запрещены: UDP-сокет допустим только на loopback SOCKS5 relay.

Эта реализация проверена Go-модульными и локальными интеграционными тестами с
поддельным SOCKS-сервером, но **не** на реальном Android/REG.RU/sing-box каскаде.
Отсутствие утечек DNS, TCP, UDP и IPv6 нельзя считать доказанным без захвата
физического трафика, тестирования Always-on/Lockdown, handover и crash.
Не включать лабораторный UDP в пользовательском VPN до завершения проверок.
