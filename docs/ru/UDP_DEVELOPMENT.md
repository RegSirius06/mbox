# Разработка UDP (после beta.3)

**Состояние: только подготовительный кодек, UDP не включён в Android и на сервере.**
Рабочий TCP/Noise-тракт и политика fail-closed остаются прежними.

Создан `common/udpwire`: версионированные UDP-датаграммы MBox с `flow_id`,
кодирование/декодирование HEV FWD UDP (`SOCKS CMD=0x05`, UDP-in-TCP), IPv4/IPv6,
предельный размер 1232 байта, отсутствие фрагментации, неявного DNS и физического
UDP fallback. Парсеры ограничивают размеры до аллокации и отклоняют повреждённые
пакеты. Покрыты unit/property/fuzz тестами.

План передачи:

```
HEV UDP-in-TCP -> локальный MBox SOCKS -> Noise/HTTPS -> REG.RU -> RU origin
 -> SOCKS5 UDP ASSOCIATE на sing-box 127.0.0.1:2080
 -> заданный outbound (включая зарубежный каскад)
```

**Нельзя** заменять sing-box произвольным `net.DialUDP` с RU VPS: иначе
пользовательский DNS/UDP может выйти напрямую из РФ, минуя выбранный каскад.

Дальше необходимы: локальный обработчик FWD UDP; ограниченные session/flow
очереди, таймауты, дедупликация; серверный SOCKS UDP ASSOCIATE; защита от
повтора и проверка обратного адреса; интеграционные тесты, Wi-Fi/LTE capture,
Always-on Lockdown, проверка падения процесса, DNS, QUIC, STUN, IPv6, нагрузка.

**QUIC** — протокол, использующий UDP. Нативный UDP даст возможность
транслировать QUIC клиентских приложений, но сам по себе не означает,
что внешний HTTPS-транспорт MBox должен перейти на QUIC.

Полная спецификация и ограничения: `docs/UDP.md`.
