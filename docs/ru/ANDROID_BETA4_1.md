# Android MBox beta.4.1: подключение и восстановление

> **Полевой статус (по сообщению разработчика):** пять сценариев связи прошли на beta.4.1; приёмка точного production-signed prerelease и физический захват утечек/Lockdown ещё ожидаются. См. [доказательства](BETA4_1_STATUS.md).

**Кандидат, не опубликован.** Android 10+ / ARM64. Старые HTTPS-only профили поддерживаются. Для QUIC нужен цифровой IPv4 endpoint и доверенный `quic_ca_pem`. Для обновления поверх предыдущей release-сборки должна использоваться та же production-подпись.

Состояния: `CONNECTING` — запуск транспорта и Noise; `VERIFYING` — ожидание нового ответа сервера на Noise ping, а не только открытого локального SOCKS; `CONNECTED` — удалённая сторона подтвердила свежую проверку; `RECOVERING` — восстановление с переподключением; `DISCONNECTED` — нет доступной физической сети; `FAILED` — локальная критическая ошибка VPN; `STOPPED` — остановлено пользователем или системой. Между фактическим отказом и ближайшей проверкой интерфейс кратковременно может показывать CONNECTED.

Go core отправляет Noise ping со случайным идентификатором каждые 30 секунд при активных потоках или 90 секунд без них (с jitter, таймаут 10 секунд). После пробуждения или выхода из Doze он получает команду проверить вне очереди. Никаких запросов к случайным сторонним сайтам. При отсутствии ответа core завершает сессию, supervisor перезапускает транспорт. Смерть QUIC gateway и HEV отдельно отслеживается в Android. При штатном восстановлении **TUN и HEV остаются**, но прежние TCP/UDP соединения могут прерваться. Из-за ограничений Android в глубоком сне строгую гарантию восстановления за 30 секунд давать нельзя.

**В публичном APK выбор транспорта автоматический.** При наличии QUIC в профиле Auto предпочитает QUIC и после подтверждённого сбоя переключается на HTTPS. Повторный QUIC — при следующем reconnect/смене сети после cooldown; работающий HTTPS ради пробы QUIC не разрывается. HTTPS-only профиль остаётся на HTTPS. Ручные режимы QUIC/HTTPS доступны только в debug-сборке. UDP приложений в HTTPS упакован в MBox поверх TCP; QUIC использует надёжные HTTP/3 streams, а не DATAGRAM. Head-of-line blocking в TCP никуда не исчезает.

**Always-on VPN** полезен, если система перезапускает VPN-службу, но **не обязателен** для восстановления зависшей живой сессии. **«Блокировать подключения без VPN» (Android Lockdown)** — системный механизм запрета обхода после остановки VPN; само приложение не заменяет Lockdown. Для подтверждения отсутствия утечек требуется физический захват пакетов.

Срок тестового сертификата QUIC — **7 декабря 2026**. См. [инструкцию TLS](QUIC_TLS_ROTATION.md): старые профили с самоподписанным leaf должны один раз перейти на доверенный CA. Нельзя отключать TLS/Noise-проверки.

Разработчик сообщил о прохождении подключения, обычного простоя с выключенным экраном, смены Wi-Fi/LTE, полной потери сети и Auto на сборке beta.4.1. Отдельно не подтверждены: принудительный Doze, убийство gateway/core/HEV, контролируемая блокировка UDP, отказ frontend, Always-on/Lockdown, перезапуск Android, packet capture, батарея, RTT и скорость. Секреты и полный `mbox://` в отчёты не прикладывать.
