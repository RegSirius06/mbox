# MBox 1.0.0-beta.4.4: первый запуск собственного сервера

[English](../SERVER_QUICKSTART.md) · [Для пользователя Android](GETTING_STARTED.md) · [Администратор](ADMIN.md)

Это руководство для владельца Linux VPS. Оно не предполагает, что читатель знает, что такое FastCGI, Noise или HMAC.

## Понадобится

- Linux VPS с доступом **root по SSH**. Origin — сервер, который принимает VPN-сессии; при необходимости трафик может идти через отдельный exit.
- Исходники MBox, необходимые системные зависимости и Go (их наличие проверяет установщик). Для QUIC/HTTPS понадобится своя схема доменов, портов и TLS.
- При желании — **отдельный** shared hosting с FastCGI (например, REG.RU) в качестве публичного HTTPS-входа. Сайт не нужно размещать на origin VPS.
- Резервная копия существующей конфигурации, если это не чистая установка.

## Что куда устанавливается

```text
Телефон --QUIC/UDP--------------------------> origin VPS -> Интернет/exit
       +--HTTPS--> REG.RU / FastCGI --> origin VPS --+
Админ --SSH-туннель--> Unix-сокет mbox-admin на VPS
```

Сайт REG.RU и origin — разные части. Сам shared hosting **не является** сервером выхода в интернет. Для новичка проще сначала настроить origin, получить рабочий профиль и только потом добавлять резервный HTTPS-вход.

## Шаг 1. Проверить установку

Скопируйте исходники на VPS в отдельный каталог и работайте из корня репозитория. На **чистом** сервере:

```bash
./install.sh --check
```

Команда только проверяет исходники и необходимые программы и не изменяет production. Ошибки устраните до продолжения.

## Шаг 2. Первичная установка

```bash
./install.sh
```

В интерактивном терминале выберите **1) New server installation**. Это соответствует `--fresh-install`. Следуйте подсказкам установщика; в конце он предложит **необязательный** мастер REG.RU. При обычном запуске из CI без терминала `./install.sh` остаётся безопасным no-op.

Если меню не нужно, явный режим:

```bash
./install.sh --fresh-install
```

**Нельзя** запускать `--fresh-install` на сервере с существующей конфигурацией MBox. Скрипт специально отказывает в этом случае.

## Шаг 3. Проверить origin

```bash
mboxctl version
mboxctl doctor
mboxctl resources
systemctl is-active mbox-server.service
```

Сохраните созданную серверную конфигурацию и ключи в защищённой резервной копии. Приватные ключи, SQLite базу и профили нельзя отправлять в Issues или публичные чаты.

## Шаг 4. Веб-панель

По умолчанию поддерживается **локальный доступ через SSH-туннель** к Unix-сокету. При необходимости установите админку явно:

```bash
./install.sh --with-admin
```

Затем на **своём компьютере**, не на VPS, откройте туннель (подставьте адрес своего VPS):

```bash
ssh -N -L 127.0.0.1:8765:/run/mbox-admin/admin.sock root@YOUR_VPS
```

В браузере: `http://127.0.0.1:8765/`. Для отдельного домена `https://panel.example.com` имеется **дополнительный** режим: он не активируется автоматически и требует настройки Caddy, allowlist Host/Origin, защищённых cookie и ограничений доступа. См. [инструкцию](MBOX_ADMIN_PUBLIC_ACCESS.md). Не открывайте сырой HTTP-административный порт в интернет.

## Шаг 5. Пользователь и Android

В панели создайте пользователя и получите `mbox://`-профиль либо постоянную HTTPS-подписку. Отправляйте её только через защищённый канал: ссылка даёт доступ к VPN. Установите подписанный APK и импортируйте профиль по [Android-инструкции](GETTING_STARTED.md).

## Шаг 6 (необязательно). REG.RU FastCGI

Если нужен HTTPS-вход, отдельный shared hosting должен поддерживать FastCGI. На **origin VPS** после первой установки мастер предложит настроить передачу файлов через SSH. Он запрашивает `user@host`, webroot, **отдельный закрытый каталог вне webroot**, `server.json` и собранный `relay.fcgi`. Затем выполняет `mboxctl relay deploy --dry-run` и только после точного ввода `DEPLOY` отправляет файлы.

**Никакой автоматической регистрации REG.RU, покупки услуги, получения паролей или обхода ограничений хостера здесь нет.** Мастер не должен сохранять SSH-пароли. Подробности: [REG.RU](REG_RU_SHARED_HOSTING.md), [мастер](BETA4_3_INSTALL_WIZARD.md).

## Обновление работающего сервера

Для проверки используйте `./install.sh --check`. Для изменения только панели — `--with-admin`. Для подписок — `--with-subscriptions`. **`--upgrade-origin` заменяет бинарники origin и перезапускает `mbox-server.service`**, поэтому обрывает текущие подключения. Его выполняют только после резервной копии и отдельно согласованного окна обслуживания. Он не должен автоматически деплоить REG.RU.

Страница с надписью beta.4.3 **не доказывает**, что установленный серверный `mboxctl` также beta.4.3. Проверяйте `mboxctl version`, состояние службы и совместимость клиентов.
