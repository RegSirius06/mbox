# Auto, HTTPS и QUIC на Android beta 4

[English](../BETA_4_TRANSPORTS.md) · [Руководство](ANDROID_BETA4.md)

**Auto доступен в обычной подписанной сборке**, а не только в debug. Его настройки QUIC приходят в `mbox://` профиле; debug-ресурсы лаборатории не используются release APK.

1. При наличии полей `transport.quic_url` + `transport.quic_ca_pem` Auto сначала выбирает **QUIC** (UDP/HTTP3 streams).
2. Если QUIC не устанавливается или Go core завершается, клиент переходит на **HTTPS/Cronet** (HTTP2/TCP). При явном выборе QUIC такой скрытой подмены транспорта нет.
3. После ошибки QUIC действует cooldown (в наблюдаемой реализации 60 секунд). Успешное HTTPS-соединение не обязано прерываться само через 60 секунд только ради пробного QUIC; при смене физической сети или следующем подключении транспорт выбирается заново.
4. Старый HTTPS-only профиль продолжает работать без QUIC. Для новой ссылки нужен доверенный сертификат, иначе не включайте прямой UDP.

**Важно:** Auto — failover с повторным подключением. Это не multipath, не бесшовный перевод TCP-потоков, не постоянное измерение ping и не гарантия, что всегда будет QUIC. Если приложение пишет HTTPS, это может быть fallback после QUIC-ошибки.

Для проверки после обезличивания логов: `adb logcat -d -s MBox:I | grep -E 'TRANSPORT|QUIC Android gateway ready|VPN CONNECTED|transport attempt failed'`. Не публикуйте полные `mbox://` ссылки.
