# Совместимость сетей — beta.4.1

[English](../NETWORK_COMPATIBILITY.md) · [Тестирование](TESTING.md)

Это **наблюдения конкретной инфраструктуры**, а не гарантия работы у каждого оператора, абонента или APN.

| Источник | Сценарий | Уровень подтверждения |
|---|---|---|
| Исторические тесты debug beta.4 | QUIC через Wi-Fi; HTTPS/Cronet на МТС/МегаФон с ограничениями; Telegram | Наблюдения разработчика для beta.4, не приёмка beta.4.1 |
| Сообщение разработчика о beta.4.1 | Подключение, простой с выключенным экраном, смена физической сети, полная потеря сети, Auto | Сообщено 5/5; не приложены модель телефона, сеть, длительности и логи точного fallback |
| Финальный production-signed APK beta.4.1 | Полная матрица, второй телефон T2/Tele2, физический packet capture, долгий soak | Пока не подтверждено |

Выбранный режим Auto **не доказывает** QUIC→HTTPS fallback, если не создавался отказ UDP при рабочем HTTPS. Прямой QUIC ходит на VPS через UDP, не через REG.RU. HTTPS использует Cronet HTTP/2 и может работать через shared hosting. В issue прикладывайте только обезличенные этапы и условия, не полный `mbox://`.
