|---|---|---|

Это результаты одного развёртывания, **не** гарантия доступности у всех операторов/абонентов. Возможны различия из-за региона, APN, домена, времени и правил фильтрации. Подписанный APK установлен, но полная транспортная приёмка именно этой сборки пока не зафиксирована. Прежняя гипотеза `.fun`/`.ru` — историческая, не подтверждённый универсальный обход.

Для диагностики собирайте обезличенные этапы DNS → TCP/UDP → TLS/QUIC → Noise → TUN → запросы приложений. Не выкладывайте секретные профили.
