# Статус MBox beta.4.2 (15.11.2026)

| Возможность / проверка | Статус | Основание / ограничение |
|---|---|---|
| Веб-панель на VPS | **Работает** | Оператор проверил создание/управление пользователями, ссылки и основные операции |
| Редактор `mbox.conf` | **Работает в развёртывании** | Смена subscription URL реально записана и применена в Caddy; потребовалась настройка systemd ReadWritePaths |
| Постоянные HTTPS-токены | **Работают** | Повторное открытие основной ссылки не создаёт новый токен; старые токены не отзывались автоматически |
| HTTPS endpoint подписок | **Работает** | Новый путь возвращает ожидаемый ответ на неправильный токен; на действующий токен Android импортировал профиль |
| Несколько подписок на Android | **Реализовано** | Применён патч, приложение установлено; полный сценарий 2 × 2 не выполнялся |
| Несколько HTTPS-входов в подписке | **Реализовано, не испытано с несколькими хостингами** | В реальном развёртывании один вход; резервный хостинг не проверен |
| Прежние прямые `mbox://` через HTTPS | **Проверено, работает** | Испытано оператором на реальном телефоне |
| Прежний QUIC-профиль | **Не работает в текущем развёртывании** | Вероятна смена привязанного TLS-сертификата; нет TLS-лога для доказательства единственной причины |
| Импорт новой HTTPS-подписки | **Проверено, работает** | Профиль получен и подключён на Android beta.4.2 |
| Подписанная Android APK | **Установлена поверх предыдущей** | `versionCode 9`, `adb install -r Success`; точный финальный APK SHA-256 ещё не опубликован |
| QR-превью | **Известная ошибка** | Текстовая ссылка доступна |
| Регистрация устройств / учёт трафика | **Отсутствует** | Есть только ограничения одновременных сессий |
| Автопереход между HTTPS-входами | **Не реализован** | Вход выбирается вручную при остановленном VPN |
| Physical leak capture / Lockdown / soak | **Не подтверждены** | Нужны отдельные физические испытания |
| Финальный GitHub CI / тег / prerelease | **Не подтверждены** | Выполнить после синхронизации полного исходного дерева |

**Решение о готовности:** пригодно для ограниченного операторского развёртывания и подготовки prerelease. Массовая production-готовность и статус RC1 пока не заявляются.

**Свойства совместимости:** старые приложения не понимают формат новых HTTPS-подписок. Старые прямые ссылки работают по проверенному HTTPS/FastCGI; для QUIC нужен актуальный профиль и корректные данные доверия сертификату. Не отключайте TLS-проверку.
