# Android MBox: инструкция для пользователя

[English](../GETTING_STARTED.md) · [Главная](../../README.ru.md)

## Что нужно

Телефон **Android 10 или новее, ARM64**, подписанный APK MBox и действительный профиль `mbox://` либо URL подписки HTTPS. Профиль выдаёт владелец сервера. Без сервера и профиля подключение невозможно. **Сам APK не содержит бесплатного публичного VPN.**

## Установка и первое подключение

1. После официальной публикации скачайте `MBox-1.0.0-beta.4.3-android-arm64.apk` из [GitHub Releases](https://github.com/RegSirius06/mbox/releases). Пока релиз не опубликован, это указание на будущий файл, а не обещание его наличия.
2. Установите APK, разрешив Android установку из выбранного источника. Не передавайте файл профиля посторонним.
3. Откройте MBox. В Settings → Profiles выберите импорт из буфера обмена (или ввод ссылки вручную). При HTTPS-подписке клиент может сохранить несколько входов и профилей.
4. Нажмите **Connect**, подтвердите системный запрос VPN. Статус **Connected via QUIC/HTTPS** означает, что MBox установил зашифрованную сессию.
5. Проверяйте работающие приложения; при необходимости отключите VPN кнопкой **Disconnect** или действием в системном уведомлении.

## Что означают статусы

- **Connecting / Verifying:** идёт подключение и проверка удалённой сессии.
- **Connected via QUIC:** прямой UDP-транспорт доступен.
- **Connected via HTTPS:** используется HTTPS-вход; он может идти через FastCGI на shared hosting.
- **Recovering:** клиент восстанавливает транспорт, не считая соединение успешно установленным до подтверждения.
- **Failed / Waiting for network:** VPN может быть недоступен. Не считайте его подключённым, если статус это не подтверждает.

**AUTO:** QUIC сначала; если QUIC не работает, переключение на HTTPS без дополнительной QUIC-попытки. Далее действует 60-секундный cooldown QUIC. Возврат на QUIC не разрывает намеренно здоровую HTTPS-сессию. При смене Wi‑Fi/мобильной сети возможна новая попытка QUIC. Смена транспорта может прервать звонок или TCP-сеанс — это не мультипутевой VPN.

## Язык, оформление и диагностика

По умолчанию язык соответствует языку телефона; доступны **русский и английский**. Оформление следует светлой/тёмной теме Android. Семь быстрых нажатий на название MBox открывают **диагностический экран**: там видны состояние, транспорт, фазы и уведомления. Полные счётчики пакетов/байтов/потоков ещё **не реализованы** — не ориентируйтесь на них как на работающий мониторинг.

## Обновление приложения

1. Получите подписанный APK из того же доверенного источника. Проверяйте, что его сертификат не изменился.
2. Установите **поверх** старого APK. Через ADB: `adb install -r MBox-1.0.0-beta.4.3-android-arm64.apk`.
3. Убедитесь, что сохранены профили и подписки, а QUIC/HTTPS работают.
4. **Не удаляйте MBox предварительно:** Android-хранилище секретов может быть потеряно при удалении приложения.

## Не подключается?

Проверьте, что есть интернет, профиль не истёк, администратор не отозвал доступ, дата/время верны, а нужный транспорт доступен в вашей сети. При отсутствии QUIC AUTO попробует HTTPS, **если он настроен**. Скопируйте только безопасные сообщения состояния; не публикуйте `mbox://`-ссылки, логины, PSK, URL подписок и приватные сертификаты.

VPN не является гарантом анонимности или обхода любых ограничений. Для строгой защиты от выхода трафика вне туннеля администратор/пользователь должен проверить Android Always-on/Lockdown и физический сетевой трафик на устройстве.
