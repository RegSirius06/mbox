# QUIC DATAGRAM — возможный проект beta.5, НЕ реализован в beta.4.1

[English](../QUIC_DATAGRAM_DESIGN.md) · [Транспорты](BETA_4_TRANSPORTS.md)

QUIC DATAGRAM (RFC 9221) передаёт зашифрованные сообщения без гарантии доставки и **без повторной передачи самим QUIC**; управление перегрузкой при этом сохраняется. В beta.4.1 native gateway передаёт аутентифицированные HTTP-запросы MBox по **надёжным HTTP/3 streams**. UDP приложений находится внутри надёжных потоков и не превращается в QUIC DATAGRAM; все задержки вложенного протокола этим не устраняются.

Для следующей версии потребуется отдельно проектировать аутентифицированную ассоциацию datagram (HTTP Datagrams / CONNECT-UDP или своё согласованное расширение), replay/nonce-защиту, квоты и MTU, потерю/перестановку пакетов, bounded queues, защищённые Android-сокеты, HTTPS fallback и миграцию серверов. Это **не** простое переключение одной настройки: нужны согласованные изменения клиента и gateway и натурные испытания. В список возможностей beta.4.1 не включать.

Источники: https://www.rfc-editor.org/rfc/rfc9221.html и https://quic-go.net/docs/http3/datagrams/.
