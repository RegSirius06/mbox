# MBox beta.4.3 — статус подготовки (17.11.2026)

[English](../BETA4_3_STATUS.md) · [Обзор](STATUS.md) · [Release notes](../../RELEASE_NOTES.ru.md)

- **Исходники:** единая целевая версия `1.0.0-beta.4.3`, Android versionCode 10. Формат Noise/wire намеренно не менялся.
- **Android:** после UX8 сообщалось о 273 пройденных Python-тестах, после UX9 — об успешной компиляции Release. **Последний подписанный APK** ещё надо собрать, проверить checksum и обновление поверх предыдущей версии.
- **Админка:** UX7 развёрнута на VPS; доступ через SSH работает. Поддержка отдельного HTTPS-домена установлена, но **по умолчанию выключена**.
- **Origin:** последний наблюдавшийся `mboxctl version` на VPS — `1.0.0-beta.4.2`. Обновлять отдельно с резервной копией, окном обслуживания и явным согласием. Замена HTML не обновляет серверный бинарник.
- **Shared hosting:** REG.RU FastCGI — отдельная площадка. Установщик предлагает интерактивный SSH-мастер только при первичной установке; обновления Android/документов не затрагивают работающий сайт.
- **Ограничения:** мониторинг CPU REG.RU и счётчики пакетов/байтов/потоков ядра Android не подключены; полный capture утечек и длительный soak не подтверждены.

**Это beta prerelease, не RC1.** Это статус **подготовки**, а не обещание, что все production-компоненты уже обновлены и прошли независимый аудит.
