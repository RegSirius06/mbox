# QUIC DATAGRAM 1.0.0-beta.4.4: реализован, криптография экспериментальна

[English](../BETA44_DATAGRAM_EXPERIMENT.md) · [Архитектура](ARCHITECTURE.md) · [Тесты](TESTING.md)

**Статус:** реализован и протестирован на телефоне, но **не** прошёл независимый аудит; это больше не идея для staging. Отдельный аутентифицированный HTTP/3 DATAGRAM переносит только **UDP DATA** уже открытых ассоциаций. TCP, Noise OPEN, открытие/закрытие UDP-ассоциации, управление и HTTPS остаются на надёжных streams. Gateway и origin связываются приватным Unix-сокетом; REG.RU DATAGRAM не передаёт.

Канал создаётся **после реального UDP-пакета**, а не при пустой ассоциации. Присоединение подтверждается аутентифицированными attach/accept; записи зашифрованы, есть replay-защита и ограниченные очереди. При простое отдельное QUIC-соединение закрывается (в испытаниях ~30–33 с), UDP временно идёт через streams; следующий реальный UDP вновь инициирует DATAGRAM. Новая аутентифицированная эпоха выводит независимые AEAD-ключи и nonce-домен, не повторяя AES-GCM счётчики. Нет периодических PING или фонового опроса DATAGRAM. Возможны потери при MTU/квотах/недоступном канале; уже выбранные пакеты не дублируются через второй путь.

**Скрытая диагностика UDP** (семь нажатий на название MBox): `AUTO` (по умолчанию), `STREAMS only` (без DATAGRAM), `DATAGRAM only` (UDP DATA **без** streams fallback в обе стороны, возможны потери; HTTPS такой канал не предоставляет). Изменение действует при следующем VPN-подключении. TCP и управление всегда надёжны. AUTO — рекомендуемый режим для батареи.

**Совместимость:** beta.4.3 использует обычные MBox streams. Первое присоединение DATAGRAM сохраняет формат эпохи 0; повторные требуют origin с rekey beta.4.4 и подходящего QUIC gateway. Формат Noise/record не следует смешивать с версией HTTP-подписки. Для gateway нужны Unix-сокет и ACL. Экономия батареи и отсутствие физических утечек пока не доказаны бенчмарком/аудитом.

**Наблюдения 21.11.2026:** Android действительно прошёл ACTIVE → fallback после ~30 секунд простоя → новый ACTIVE после намеренного UDP без перезапуска Noise. Разработчик проверил экран выключен, режим полёта и Wi-Fi/мобильную сеть. Нет контрольных ваттметрических замеров, 24-часового soak, независимого криптоаудита и полного packet-capture/Lockdown.
