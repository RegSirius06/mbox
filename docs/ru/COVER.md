[English](../COVER.md)

Cover traffic — опциональная серверная активность через публичный frontend, когда нет недавно активных аутентифицированных MBox-сессий. По умолчанию выключена. При успешном OPEN текущий cover-профиль отменяется; цикл не реже раза в секунду проверяет реальные сессии и переходит в состояние `suppressed`. Если хотя бы одна сессия активна в пределах `idle_after_ms`, новые cover-запросы не начинаются. Штатный CLOSE снимает ограничение сразу; потерянная сессия перестаёт считаться активной после `idle_after_ms`. Перед возобновлением действует случайная пауза start grace. Уже выполнявшийся запрос может успеть завершиться.

**Компромисс:** подавление снижает расход CPU на общем хостинге, но создаёт статистическую корреляцию активности cover с подключениями реальных пользователей. Cover использует заголовки Go HTTP-клиента, а не полноценный браузерный отпечаток.

```bash
mboxctl cover simulate --hours 24
mboxctl cover test
mboxctl cover enable
mboxctl cover status
```

Cover меняет историю запросов frontend, но не скрывает отсутствие трафика на конкретном мобильном last-mile.
