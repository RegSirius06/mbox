# Статус MBox — 1.0.0-beta.4.1

[English](../STATUS.md) · [Подробный статус](BETA4_1_STATUS.md) · [Примечания к релизу](../../RELEASE_NOTES.ru.md)

**Исходный кандидат:** `1.0.0-beta.4.1`, Android `versionCode=8`, application ID `io.mbox.android`. Wire beta.4 и HTTPS-only профили совместимы. Есть аутентифицированный Noise heartbeat и независимый контроль QUIC gateway/HEV; Auto по-прежнему переключает транспорт с переподключением.

**По сообщению разработчика:** обычное подключение, простой с выключенным экраном, Wi-Fi↔LTE, полная потеря сети и Auto пройдены на сборке beta.4.1. Go client/server и native QUIC race-тесты пройдены, debug APK собран. Полная приёмка финального APK с production-подписью и CI ещё ожидается.

**Открыто:** нет независимого захвата физического интерфейса для проверки утечек и полной матрицы Android Lockdown; тестовый QUIC-сертификат с привязкой к старому leaf истекает 7 декабря 2026 г., CA/ротация на VPS не внедрены. Не заявляем универсальный обход DPI, идентичность браузеру или независимый аудит. Документы beta.4/3/2 остаются историческими.
