# Статус MBox — 1.0.0-beta.4.4 (до публикации)

[English](../STATUS.md) · [Примечания](../../RELEASE_NOTES.ru.md) · [Чек-лист](../../RELEASE_CHECKLIST.ru.md)

**Локальные исходники/production:** Android `versionCode=11`, origin с rekey/режимами UDP и панель подписок обновлены на VPS разработчика. Реально проверены отдельные SOCKS5-выходы DK/KZ; beta.4.3 обновила подписку и подключилась по старому маршруту DK. По Android/server логам подтверждены DATAGRAM по требованию, ~30 секунд простоя и повторное присоединение после нового UDP. Отмечены успешные экран выключен, режим полёта, Wi-Fi/мобильная сеть. `install.sh --check`, Go/race и профильные тесты прошли, но это **не** полноценная проверка fresh-install/rollback и финального GitHub релиза.

**GitHub:** в main пока beta.4.3 до явного коммита и push beta.4.4. Последний production-signed APK и факт создания GitHub prerelease проверяются отдельно. REG.RU — отдельный FastCGI-вход, автоматически не обновлялся.

**Открыто:** высокий риск CPU/воркеров REG.RU; измерение батареи, физические IPv4/IPv6/DNS/UDP/Lockdown, длительный soak, независимый криптоаудит и проверка уведомления beta.4.3 → beta.4.4. Нет гарантии отсутствия любых утечек/обхода DPI.
