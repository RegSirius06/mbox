# Статус MBox — 1.0.0-beta.4.3

[English](../STATUS.md) · [Примечания](../../RELEASE_NOTES.ru.md) · [Процесс выпуска](RELEASE_ENGINEERING_BETA43.md)

**Кандидат в исходниках:** beta.4.3; Android `versionCode=10`, `io.mbox.android`. Последние сообщённые проверки: 273 Python-теста пройдены после UX8, компиляция release Android прошла ещё раз после UX9. До публикации требуются отдельные доказательства для **последнего подписанного APK**, проверка контрольной суммы, установки поверх старой версии и CI.

**VPS:** Admin UX7 развёрнута и работает, но `mboxctl version` показывал beta.4.2. Для origin требуется отдельное обновление с резервной копией и окном обслуживания. FastCGI frontend на shared hosting — тоже отдельная площадка. Пока не проверены все компоненты, нельзя объявлять весь production обновлённым.

**Открытые вопросы безопасности:** физический захват IPv4/IPv6/DNS/UDP, полная матрица Android Lockdown, длительный soak и безопасная ротация TLS остаются отдельными задачами. Независимого security-аудита и гарантии обхода DPI нет. Метрики CPU REG.RU и счётчики пакетов/байтов/потоков Android-ядра не интегрированы.
