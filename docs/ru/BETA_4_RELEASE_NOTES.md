# MBox 1.0.0-beta.4 — заметки к релизу (ЧЕРНОВИК)

[English](../BETA_4_RELEASE_NOTES.md)

> **Это черновик, а не объявление опубликованной версии.** Перед публикацией необходимо собрать, подписать, проверить и испытать именно release APK. Последней опубликованной бетой пока может оставаться beta 3.

## Главные изменения

- **UDP приложений:** UDP-потоки передаются через MBox, в том числе по прежнему HTTPS/TCP-маршруту для сетей с ограниченным доступом. В разрабатываемой сборке UDP проверяли через Android STUN.
- **Прямой native QUIC / HTTP/3:** связь с QUIC gateway на VPS поверх UDP без промежуточного FastCGI-хостинга. Используются HTTP/3 streams, **не QUIC DATAGRAM**.
- **Auto на Android:** при неудаче QUIC переподключается по HTTPS; при смене физической сети выбор транспорта пересматривается. Это failover соединения, а не объединение каналов.
- **Изоляция шлюза:** QUIC запускается с непривилегированным systemd DynamicUser, `NoNewPrivileges`; оценка `systemd-analyze security` изменилась с **9.6 UNSAFE** до **3.8 OK**. Это оценка конфигурации sandbox, **не сертификат безопасности**.
- **Диагностика:** появились более подробные сообщения о стадиях QUIC и выборе транспорта — для поиска ошибок на конкретных операторах/хостингах.

## Результаты полевых проверок

На Android разработчика работали ручные HTTPS и QUIC, Auto при переходе Wi-Fi/мобильная сеть, QUIC/Noise handshake. Сообщалось об одном успешном тесте на **МегаФоне** в ограниченной сети. Go tests/race/vet и **96 Python-тестов** прошли, debug APK собрался. Это **не** подтверждение работы ещё не собранного release APK и не гарантия для всех операторов.

## Известные ограничения и проблемы

- 12 ноября shared-hosting FastCGI отвечал HTTP 500. После перезапуска обработчиков связь восстановилась. **Причина пока неизвестна** — поэтому особенно важны полевые баг-репорты.
- Отсутствие утечек на всех физических интерфейсах, fail-closed при любых сбоях Android и долговременная стабильность при большом количестве пользователей **ещё не подтверждены независимой проверкой**.
- Нет гарантии универсального обхода DPI; Chromium-derived HTTPS не тождественен полному fingerprint браузера.
- Нет QUIC DATAGRAM, одновременного multipath, бесшовной миграции открытых потоков и готовых настольных клиентов.
- Совместимость с предыдущими экспериментальными бетами **не гарантируется**.
- Лабораторный сертификат QUIC нужно обновить до истечения срока (по имеющимся данным — **07.12.2026**) с контролируемым обновлением доверия у клиентов.

## Для тестировщиков и разработчиков

Ошибки отправляйте в [GitHub Issues](https://github.com/RegSirius06/mbox/issues), предложения кода — через Pull Request. Прикладывайте только очищенные логи, модель/версию устройства, оператора, режим транспорта, время с часовым поясом и воспроизведение. Не публикуйте provisioning-ссылки, PSK или закрытые ключи. См. [инструкцию по тестам](BETA_4_FIELD_TESTING.md) и [правила участия](../../CONTRIBUTING.ru.md).
