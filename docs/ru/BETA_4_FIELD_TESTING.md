# Полевые испытания beta 4

[English](../BETA_4_FIELD_TESTING.md) · [Матрица сетей](NETWORK_COMPATIBILITY.md)

На **debug** Android клиента разработчик проверил: QUIC по Wi-Fi, HTTPS при ограничениях МТС/МегаФон, Auto/failover, Telegram и многократные переподключения. Подписанный **release** APK успешно установлен, версия проверена, но полная независимая матрица его транспортов пока не завершена. Tele2/T2 на втором телефоне, физический packet capture и длительный soak не подтверждены.

Для [GitHub Issues](https://github.com/RegSirius06/mbox/issues) полезны оператор, режим, модель телефона/Android, время и обезличенные стадии логов. Не публикуйте целиком `mbox://`, PSK, секреты VPS или сырой чувствительный logcat.
