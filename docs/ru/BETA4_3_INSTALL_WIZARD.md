# MBox beta.4.3 — интерактивная установка

**Первичная установка:** на новом origin-сервере запускается `./install.sh` в интерактивном терминале. Пункт `1` соответствует `--fresh-install`: настройка origin, проверка работы сервиса и предложение установить FastCGI-релей на REG.RU. Мастер `tools/relay-setup.sh` сам спросит SSH-логин `user@host`, каталог сайта, приватный каталог *вне* webroot, файл текущего runtime-конфига и бинарник. Сначала — `--dry-run`, затем отдельное подтверждение `DEPLOY`. Пароли не сохраняются, SSH-авторизация выполняется средствами SSH. Пути и действующий HMAC-ключ необходимо проверить. Это не интеграция с аккаунтом REG.RU через API.

**Существующая работающая система:** `./install.sh --check` проверяет требования без изменений; `--with-admin` обновляет админку/CLI без перезапуска origin; `--with-subscriptions` — подписки и админку; `--upgrade-origin` — **отдельно одобренное обновление ядра с перезапуском** и возможным обрывом соединений. Мастер REG.RU при обновлениях не запускается. Запуск без флагов в неинтерактивной среде по-прежнему ничего не меняет.

**Единство релиза:** `VERSION`, `mboxctl version`, `versionName` и `versionCode` Android, проверка APK должны соответствовать beta.4.3. На VPS прежний номер останется до явного развёртывания обновлённой серверной части: замена HTML версии origin не меняет. Нельзя ограничиваться ручной заменой строки версии на сервере.

**Android:** цвета Connect/Disconnect определяются парой `values` и `values-night`, для обоих состояний требуется читаемый контраст. Патч не изменяет VPN-транспорт, не обращается к REG.RU и ничего не развёртывает в production.
