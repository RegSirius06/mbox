# MBox 1.0.0-beta.4 — предварительный релиз

[English](RELEASE_NOTES.md) · [Android](docs/ru/ANDROID_BETA4.md) · [Исходники](https://github.com/RegSirius06/mbox)

**Тип выпуска:** beta/prerelease. **Платформа:** Android 10+ (API 29), ARM64. Имя APK: `MBox-1.0.0-beta.4-android-arm64.apk`, пакет `io.mbox.android`, `versionCode=7`. Профиль `mbox://` выдаётся администратором отдельно; внутри APK **нет** публичного адреса и сертификата конкретного QUIC-сервера.

## Главное в beta 4

- **Нативный QUIC/HTTP3 через внешний UDP** напрямую к QUIC gateway на VPS. Транспорт использует HTTP/3 streams, не QUIC DATAGRAM.
- **HTTPS/Cronet** через доступный frontend и FastCGI с сохранением поддержки прикладного UDP внутри зашифрованных MBox-записей поверх TCP.
- **Auto:** сначала QUIC, при ошибке — HTTPS и реконнект; при смене сети переоценивает транспорт. Без QUIC-параметров в профиле используется HTTPS.
- **Упрощённый Android UI:** главное действие Connect/Disconnect, статус и Settings. В debug доступна лабораторная диагностика.
- QUIC-настройки — два поля в профиле: `transport.quic_url` (IPv4, HTTPS URL с портом) и публичный X.509 `transport.quic_ca_pem`.
- Исправлен запуск локального QUIC Unix-сокета без developer mode; опасные диагностические настройки по-прежнему запрещены в release.
- Подписанная сборка с постоянным сертификатом; встроены `libmbox.so` и `libmboxquic.so`.

## Проверки, подтверждённые разработчиком

- На Arch: `pytest` — **110 passed**; Gradle `assembleRelease` — **BUILD SUCCESSFUL**; проверка APK показала release-манифест, обе библиотеки и ожидаемый сертификат подписи.
- APK был установлен на Android: `versionName=1.0.0-beta.4`, `versionCode=7`.
- На debug-сборке проверены: QUIC на Wi-Fi, HTTPS на ограниченных МТС/МегаФон, Auto, многократные переподключения и Telegram.
- **Не приравнивать эти проверки к полной полевой приёмке именно подписанного release APK.** Tele2/Т2 на втором устройстве ещё не подтверждён; полный packet capture не выполнен.

## Как проверить APK

SHA-256 **конкретной проверенной сборки**:

```text
c3b1cbcb1b4b472aba35237657c2834a2aa8f032d861cbf817f5a5b9f18b43e1
```

SHA-256 сертификата подписи (не SHA-256 файла):

```text
17fd9f930b8356beca8251dd215220771a3d020e56fb6a703b526c35cccd7586
```

Эти хеши относятся к приведённому APK. При любой пересборке хеш файла нужно перепроверить; если он изменился, необходимо обновить release notes **до публикации**. Хеш сертификата должен остаться прежним.

## Известные ограничения и безопасность

- Нет независимого аудита, полного физического теста отсутствия DNS/IPv4/IPv6-утечек и длительного soak; **никаких гарантий «без утечек»**.
- Android Always-on и Lockdown пользователь включает в настройках системы, после чего проверяет поведение на своём устройстве.
- Auto — fallback, а не работа двух транспортов параллельно; возможны обрывы активных соединений.
- Срок тестового сертификата QUIC — **07.12.2026**; администратору нужно обновить его и доверенный сертификат в выданных профилях без отключения TLS-проверки.
- Профили содержат секреты; не публикуйте их. Из-за различия подписи старую debug-сборку нельзя обновить на release поверх: после **надёжного сохранения** профиля может потребоваться удаление debug APK.
