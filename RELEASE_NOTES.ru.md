# MBox v1.0.0-beta.4.3 — примечания к предварительному выпуску

[English](RELEASE_NOTES.md) · [README](README.ru.md) · [Чек-лист](RELEASE_CHECKLIST.ru.md)

**Android 10+ · ARM64 · `io.mbox.android` · `versionCode=10`. Это beta, не RC1.** Перед публикацией требуется проверка итогового подписанного APK и согласование серверного развёртывания.

## Что нового

**Android:** единый обновлённый интерфейс вместо смеси страниц и системных меню; русская и английская локализация, автоматический выбор светлой или тёмной темы устройства, исправленный контраст основных кнопок, фирменная иконка MBox. Раздельные экраны профилей, подписок и настроек; импорт из буфера, ручной импорт, удаление прямого профиля с подтверждением. Системное уведомление возвращает в приложение и позволяет отключить VPN. Семь нажатий на заголовок MBox открывают диагностическую пасхалку.

**Обновления:** ссылка на GitHub Releases и уведомление о более новой версии с действиями «Остаться в MBox» и «Открыть GitHub»; проверка не использует прямое соединение в обход VPN.

**Веб-панель:** современная навигация по клиентам, подпискам, настройкам, диагностике. Рекомендуется SSH-туннель, но есть отдельный **опциональный** режим домена HTTPS с Caddy и явными ограничениями доступа. Публичный домен не включён по умолчанию.

**Установка и REG.RU:** интерактивное меню `install.sh` при первом запуске на TTY, затем предложение отдельно настроить FastCGI-релей на REG.RU с dry-run и подтверждением `DEPLOY`. Управляемый деплой/откат релея умеет освобождать старые FastCGI-процессы после замены бинарника. Произвольный ручной `scp` такого эффекта не гарантирует.

## Совместимость

Схема Noise/wire, API origin, формат `mbox://` и HTTPS-подписок **не изменялись намеренно**. AUTO предпочитает QUIC, при сбое переходит на HTTPS с 60-секундным cooldown для QUIC. Переключение может оборвать действующие потоки; QUIC DATAGRAM и бесшовный multipath не реализованы. Для HTTPS по-прежнему нужен рабочий релей; для QUIC — корректный TLS профиль.

**Сервер и Android не обновляются одной кнопкой.** Известное состояние на 17.11.2026: админка UX7 на VPS развёрнута, но `mboxctl version` там показывал beta.4.2; origin требует отдельного обновления с резервной копией. Изменение номера HTML не обновляет серверный бинарник.

## Известные ограничения

- REG.RU CPU-мониторинг **не подключён**: карточка — статус интеграции, не реальные проценты нагрузки.
- Точные счётчики пакетов, байтов и потоков в Android диагностике пока недоступны.
- Тесты на физическом интерфейсе (IPv4, IPv6, DNS, UDP), полная матрица Android Lockdown и длительная эксплуатация должны быть подтверждены отдельно. Не заявляем «100% без утечек», абсолютную анонимность или универсальный обход DPI.
- Публичная веб-панель требует HTTPS, правильного доверенного proxy/Origin, дополнительной аутентификации и ограничения доступа; SSH — безопасный вариант по умолчанию.
- Предыдущая схема доверия QUIC TLS может требовать миграции/ротации сертификата. Декоративная beta.4.3 это не исправляет.

## Состояние проверки и артефакты

Разработчик сообщил о **273 пройденных Python-тестах** и успешной компиляции Android Release после UX8; после последующего UX9 кнопки также были скомпилированы. Перед публикацией необходимо повторить тесты на **финальном коммите**, подписать APK прежним сертификатом и повторить `adb install -r` на реальном телефоне. Не выдаём выполненные до финального коммита тесты за итоговую приёмку.

Ожидаемый файл: `MBox-1.0.0-beta.4.3-android-arm64.apk` и соответствующий `.sha256`; фактический SHA-256 публикуется только после новой подписи. Debug APK, личные профили, HMAC/PSK и signing keystore в релиз **не входят**.
