# MBox v1.0.0-beta.4.1 — примечания к prerelease

[English](RELEASE_NOTES.md) · [Android](docs/ru/ANDROID_BETA4_1.md) · [Фактические испытания](docs/ru/BETA4_1_STATUS.md)

**Android 10+; ARM64; пакет `io.mbox.android`; versionCode 8.** Подписанный prerelease собирается владельцем из проверенного коммита. Этот файл **не доказывает**, что GitHub release или финальный APK уже опубликован.

## Исправлено относительно beta.4

- Запуск локального SOCKS больше не является достаточным критерием CONNECTED: используется существующий аутентифицированный Noise `framePing`/pong — до установки статуса и периодически после, включая пробуждение/выход из Doze.
- Android отдельно контролирует QUIC gateway и HEV при работающем Go core; транспорт обычно восстанавливается без снятия TUN, с ограниченным backoff и fallback Auto.
- Появились VERIFYING/RECOVERING и подробные этапы в интерфейсе/уведомлении. Добавлены native QUIC race CI, интеграционные TLS-тесты и проверка содержимого release APK.
- Подготовлены операторские инструменты CA/leaf ротации QUIC и инструкции; **на VPS автоматически не устанавливаются**.

**Публичный интерфейс:** ручного переключателя транспорта нет. Для профилей с QUIC принудительно используется Auto, даже если прежняя debug-сборка сохранила ручной выбор; HTTPS-only профили остаются на HTTPS. Ручной выбор доступен только в debug.

**Совместимость:** Noise/wire beta.4 не изменены; старый сервер, HTTPS-only и существующие QUIC-профили поддерживаются с учётом срока сертификата. Auto может оборвать открытые потоки и не обещает бесшовного QUIC↔HTTPS. QUIC передаёт HTTP/3 streams, не DATAGRAM; UDP приложений через HTTPS остаётся поверх TCP.

## Доказательства и границы

Разработчик сообщил об успешных пяти тестах beta.4.1: подключение, простой при выключенном экране, Wi-Fi/мобильная сеть, полная потеря сети и Auto. Go client/server и native QUIC race-тесты прошли; Android debug APK собран. CI на итоговом коммите, проверка production-signed APK, имитация зависшего gateway, физический packet capture (IPv4/IPv6/DNS/TCP/UDP), Lockdown, длительный soak и сравнение браузерных fingerprint **пока не подтверждены**. Независимого аудита не было; гарантии отсутствия утечек и прохождения любого DPI нет. См. [тестирование](docs/ru/TESTING.md) и [маскировка](docs/ru/TRAFFIC_CAMOUFLAGE_LIMITS.md).

Тестовый QUIC-сертификат истекает **07.12.2026**. При переходе со старого прикреплённого self-signed leaf требуется аутентифицированная миграция профиля. Отключать проверку TLS нельзя. См. [инструкцию администратора](docs/ru/QUIC_TLS_ROTATION.md).

## Артефакт релиза — заполнить ПОСЛЕ финальной production-подписи

- APK: `MBox-1.0.0-beta.4.1-android-arm64.apk`
- SHA-256 APK: **Вычисляется отдельно на подписанном APK и выкладывается как `.sha256` рядом с файлом**
- SHA-256 сертификата APK: **Подтверждается отдельно сравнением с прежним доверенным отпечатком**
- Исходники: **тег `v1.0.0-beta.4.1`; проверить коммит по GitHub CI**
- Проверки подписанного APK: **см. чек-лист и отдельные результаты, а не считайте этот файл доказательством**

```bash
sha256sum dist/release/MBox-1.0.0-beta.4.1-android-arm64.apk
MBOX_RELEASE_SIGNER_SHA256='<проверенный-существующий-отпечаток>' \
  ./tools/check-production-apk.sh dist/release/MBox-1.0.0-beta.4.1-android-arm64.apk
```

Публиковать GitHub **prerelease** после просмотра [чек-листа](RELEASE_CHECKLIST.ru.md). Не прикреплять debug/unsigned APK и не выкладывать `mbox://`, PSK, ключи или сырые чувствительные логи.
