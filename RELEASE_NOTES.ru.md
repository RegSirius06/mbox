# MBox v1.0.0-beta.4.4 — примечания к prerelease

[English](RELEASE_NOTES.md) · [Главная](README.ru.md) · [Чек-лист](RELEASE_CHECKLIST.ru.md)

**Android 10+, ARM64, `io.mbox.android`, versionCode 11. Экспериментальный prerelease, не RC1.** Текст подготовлен до публикации; финальные SHA и APK нужно подтвердить.

## Изменения

- **Настоящий QUIC DATAGRAM для UDP приложений**: отдельный аутентифицированный HTTP/3 канал, AEAD-ключи и replay-защита по новым эпохам, ограниченные очереди и STREAMS fallback. **Нет непрерывных DATAGRAM PING**. При новом реальном UDP-трафике засыпающий канал повторно присоединяется без новой Noise-сессии. TCP через DATAGRAM не передаётся.
- **Скрытый выбор передачи UDP:** AUTO (по умолчанию), STREAMS only, DATAGRAM only. Последний намеренно не делает UDP fallback, поэтому возможны потери UDP; TCP и управление всегда надёжны. Обычным пользователям настройка не показывается.
- **Энергоэффективность и восстановление Android:** меньше опросов сети и обновлений UI, дедупликация проверки после пробуждения, запуск канала по фактическому UDP. Разработчик испытал сон экрана, отсутствие сети, смену Wi-Fi/мобильной сети и восстановление. Близкий расход батареи — наблюдение, **не контролируемый бенчмарк**.
- **Входящие транспорты:** прямой QUIC gateway и HTTPS/Cronet через необязательный FastCGI, автоматический резервный путь. DATAGRAM не требует менять REG.RU.
- **Несколько стран выхода:** `MBD2` с аутентифицированным `egress_id` выбирает разрешённый локальный SOCKS5 origin; подписка v2 возвращает основной и именованные выходы по одной URL. beta.4.3 получает v1 и выход по умолчанию. Реально проверены DK/KZ через разные SOCKS5.
- **Панель и интерфейс:** скрытая диагностика в релизном APK, аккуратный выбор профиля и светлая/тёмная тема, SSH-панель с явно включаемым HTTPS, подпись для выхода по умолчанию, добавление страны. Сохранено ненавязчивое уведомление о GitHub Releases; нет прямого обхода VPN ради проверки обновлений.
- **Эксплуатация:** read-only `install.sh --check`, раздельные режимы установки и обновления, подпись APK, резервные копии/откат, сборка и самопроверка relay, инструменты recycle FastCGI. Обновления origin, gateway и frontend независимы.

## Совместимость и безопасность

- **Подписки v1/v2** и **Noise OPEN MBD1/MBD2** — разные уровни. Маршрут по умолчанию нужен клиенту без `egress_id`; beta.4.3 реально проверена. Совместимость с произвольными старыми или неаутентифицированными клиентами не обещается.
- Сохраняются PSK профилей, URL подписок и сертификат подписи APK. Нельзя публиковать секретные ссылки, пароли, ключи и runtime-БД.
- Дополнительная криптография DATAGRAM/reattach экспериментальна. **Нет независимого security-аудита, подтверждённого отсутствия физических утечек и гарантии обхода любого DPI.**

## Известные проблемы и задачи

1. **Высокая — CPU/воркеры FastCGI на REG.RU:** квоты shared hosting могут ограничивать или завершать процессы при нагрузке; реальных CPU-метрик провайдера нет. Исправление не подтверждено, relay без согласования не обновлять.
2. **Средняя — батарея Android:** контролируемых замеров и длинного soak нет; фоновую активность, QUIC-handshake и пробуждения радиомодуля нужно профилировать.
3. **Высокая по необходимости проверки — утечки/Lockdown:** физический capture IPv4/IPv6/DNS/UDP, смена сетей, независимый аудит и TLS-ротация остаются задачами.
4. **Средняя — уведомление об обновлении:** переход beta.4.3 → beta.4.4 нужно испытать после публикации; проверка работает внутри VPN, уведомления могут быть запрещены системой.
5. **UX:** страны равноправны по маршрутизации, но конфигурационный default сохраняется ради прежних клиентов.

## Условия публикации

Зелёный CI на точном SHA; полный `RELEASE_CHECKLIST.ru.md`; production-signed `MBox-1.0.0-beta.4.4-android-arm64.apk` и `.sha256` со старым сертификатом; тег `v1.0.0-beta.4.4` на этом SHA и GitHub **Pre-release**. Финальные контрольные суммы нельзя подставлять до сборки и подписи.
