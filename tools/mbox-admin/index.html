Транспорты и диагностика

QUIC — прямой UDP-транспорт при наличии подходящего клиентского профиля.

HTTPS / FastCGI — альтернативный путь через настроенные веб-входы.

Статус отдельных входов здесь не измеряется. Для реальных проверок используй Doctor и Resources.

Рекомендуется SSH-доступ. По желанию администратор может включить HTTPS-домен через защищённый reverse proxy. Редактирование конфигурации сохраняет проверку ревизии и подтверждение APPLY. Секреты не отображаются в обзоре.

Создать клиента

Один клиент = индивидуальные PSK и профиль. Лимит IP и квоты трафика пока не реализованы.

Создать несколько клиентов

Создаёт от 2 до 100 пользователей с отдельными PSK: user-001, user-002 и т.д. Повторный префикс с существующими ID отклоняется. Лимит — одновременные сессии, а не зарегистрированные устройства.

Подписки и точки входа

Показать подписку — открывает одну и ту же постоянную ссылку, без повторной выдачи токена. Если раньше выпускались разные ссылки, они остаются действительными; столбец «Ссылок» показывает их количество. Кнопка «Отозвать подписки» отключает ВСЕ ссылки выбранного пользователя. После отзыва можно получить новую постоянную ссылку. Постоянная HTTPS-подписка; при её обновлении Android получает актуальные MBox-профили. Дополнительные точки входа (например, REG.RU и Beget) должны вести к одному origin с совместимыми camouflage-путями.
Один вход — один публичный HTTPS-релей к origin. Для Beget укажи его рабочий FastCGI URL, а не адрес VPS. Записи обновляют подписки динамически.

Конфигурация MBox

Все параметры mbox.conf. Изменения применяются после проверки; для части параметров сервер будет перезапущен один раз. Секреты скрыты и не меняются, пока ты не введёшь новое значение.

Путь подписки: поле subscription.public_url. Например https://lupka.zalupka.fun/api/v2. При изменении старые ссылки перестанут открываться — новые адреса нужно отправить пользователям.
